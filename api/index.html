02 / TARIFNI TO‘G‘RI TUSHUNISH

Free tier ≠ cheksiz foydalanish.

Free tier
Provayderning bepul rejasi. Model va xizmat bo‘yicha o‘z limitlari bor.
Billing tier
Akkaunt yoki loyiha darajasi. Bizning billing dashboard holatimiz hali tasdiqlanmagan.
Serving tier
So‘rovning xizmat ko‘rsatish turi. Gemini’dagi standard qiymati pullik billing dalili emas.

04 / SAYTGA ULASH

Kalit serverda. Foydali natija saytda.

  • Render APIKalitni server secrets’dan oladi; sessiya, vakolat, savol hajmi va budjetni tekshiradi.
  • 401 / 403Sozlama yoki ruxsat xatosi. Cheksiz retry qilinmaydi.
  • 429Qaysi limit va kutish muddati aniqlanadi. Bir project ichida kalit aylantirish kvotani tiklamaydi.
  • Timeout / 5xxCheklangan retry, so‘ng mos boshqa provayder. Asosiy sayt AI’siz ham ishini davom ettiradi.
  • Keyingi sifat sinoviBir xil o‘zbekcha topshiriqlar, fakt aniqligi, JSON, uzun kontekst va ko‘p foydalanuvchi holatlari.
